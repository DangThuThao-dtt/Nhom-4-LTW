# Huong dan cai dat moi truong du an

## 1. Cong cu su dung

- XAMPP: cung cap Apache, PHP va MySQL/MariaDB.
- Visual Studio Code: dung de chinh sua ma nguon.
- Git: quan ly phien ban ma nguon.
- GitHub: luu tru va chia se ma nguon.

## 2. Khoi dong moi truong

1. Mo XAMPP Control Panel.
2. Nhan Start tai Apache.
3. Nhan Start tai MySQL khi can su dung co so du lieu.
4. Mo thu muc du an bang Visual Studio Code.

## 3. Truy cap du an

Mo trinh duyet va truy cap:

http://localhost/Nhom-4-LTW/

## 4. Kiem tra moi truong

- Kiem tra Apache da khoi dong.
- Kiem tra trang du an co hien thi tren trinh duyet.
- Khi can su dung co so du lieu, kiem tra MySQL va cau hinh ket noi.

## 5. Luu y

- Luu cac thay doi truoc khi commit.
- Khong dua mat khau vao repository cong khai.
- Dong bo ma nguon voi GitHub khi cap nhat du an.
