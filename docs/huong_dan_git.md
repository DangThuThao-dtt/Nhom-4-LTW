# Huong dan su dung Git va GitHub

## 1. Git va GitHub

- Git la cong cu quan ly phien ban ma nguon.
- GitHub la nen tang luu tru va chia se repository truc tuyen.

## 2. Clone repository

Sao chep repository tu GitHub ve may tinh de lam viec voi ma nguon du an.

Repository cua nhom:

https://github.com/DangThuThao-dtt/Nhom-4-LTW

## 3. Kiem tra thay doi

Mo Terminal trong VS Code va chay:

git status

Lenh nay giup kiem tra trang thai cac file trong repository.

## 4. Commit thay doi

Sau khi tao hoac chinh sua file, co the chay:

git add docs/huong_dan_git.md
git commit -m "Them huong dan su dung Git"

## 5. Push thay doi

Day commit len repository GitHub bang lenh:

git push origin main

## 6. Pull thay doi

Lay cac thay doi moi nhat tu nhanh main:

git pull origin main

## 7. Luu y

- Kiem tra file truoc khi commit.
- Su dung tai khoan GitHub cua ban than.
- Dong bo ma nguon truoc khi tiep tuc lam viec.
