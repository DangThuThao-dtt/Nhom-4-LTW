# Kiem thu moi truong du an

## 1. Muc dich

Kiem tra cac cong cu va moi truong can thiet de mo va chay du an web.

## 2. Danh sach kiem tra

- [ ] XAMPP da duoc cai dat.
- [ ] Apache co the khoi dong.
- [ ] PHP co the chay qua trinh duyet.
- [ ] Visual Studio Code mo duoc thu muc du an.
- [ ] Git duoc cai dat va co the su dung.
- [ ] Repository co the duoc clone tu GitHub.

## 3. Cach kiem tra

1. Mo XAMPP Control Panel.
2. Kiem tra trang thai Apache.
3. Mo du an bang Visual Studio Code.
4. Mo Terminal va chay lenh git status.
5. Truy cap trang web de kiem tra ket qua.

## 4. Ket qua kiem tra

Ghi lai ket qua thuc te sau khi kiem tra tung muc.

Khong danh dau hoan thanh neu chua thuc hien kiem tra.

## 5. Ket luan

Tong hop cac cong cu da hoat dong va nhung van de can khac phuc neu co.
